📊 Live Streaming Sales Analytics Dashboard

Analisis performa penjualan live streaming menggunakan Microsoft Excel dengan fokus pada Data Cleaning, Data Quality Assessment, Business Validation, Exploratory Data Analysis (EDA), dan Dashboard Reporting.

Project Overview

Proyek ini bertujuan untuk menganalisis performa penjualan melalui live streaming dengan mengevaluasi kualitas data, performa kategori produk, perilaku penonton, serta faktor-faktor yang memengaruhi pendapatan.

Excel Pivot Table Dashboard Data Cleaning EDA

Dataset Information

  • 1.500 sesi live streaming
  • 11 atribut utama
  • Kategori: Elektronik, FMCG, Kosmetik, Pakaian, Aksesoris
  • Analisis berbasis Revenue, Viewer, Rating, dan Durasi Live

Data Quality Assessment

Permasalahan Jumlah Treatment
Missing Durasi_Menit 150 Median Imputation (96 menit)
Missing Rating 400 Median Imputation (3.9)
Rata_Penonton = 0 250 Imputasi berdasarkan rasio Peak Viewer
Inkonsistensi Kategori 9 Variasi Standardisasi Kategori
Anomali Bisnis 196 Dikeluarkan dari analisis revenue

Business Rule Validation

  • Validasi transaksi dengan Item_Terjual > 0 tetapi Pendapatan = 0
  • Validasi data viewer yang tidak konsisten
  • Validasi kategori produk yang tidak standar

Key Insights

📈 Elektronik Mendominasi Revenue

Kategori Elektronik menghasilkan 78,2% total pendapatan meskipun jumlah item terjual lebih rendah dibanding FMCG, Kosmetik, dan Pakaian.

🛒 FMCG Memiliki Volume Penjualan Tinggi

FMCG menjadi kategori dengan jumlah item terjual tertinggi, namun memiliki nilai transaksi per item yang relatif rendah.

📊 Data Quality Berpengaruh Terhadap Analisis

Ditemukan 196 transaksi tidak valid yang berhasil diidentifikasi melalui Business Rule Validation.
